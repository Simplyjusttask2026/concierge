# Owner photos - Simply Just Task

Upload REAL job photos here. The social crew pulls from this folder FIRST.

## How to upload (phone or computer)
1. Open: https://github.com/Simplyjusttask2026/concierge/upload/main/photos
2. Drag / choose your photos
3. Click the green Commit changes button

## Naming (helps the crew pick the right photo)
- lawn-apopka-01.jpg
- handyman-mounting-01.jpg
- cleaning-01.jpg
- pressure-wash-01.jpg
No spaces in the file name if you can.

## How the crew pulls them
Raw file URL pattern:
https://raw.githubusercontent.com/Simplyjusttask2026/concierge/main/photos/<your-file-name>

Crew order: 1) real photo from here, 2) free AI image if no real photo matches.
Every post gets an image, branded with your logo. No image = no post.
